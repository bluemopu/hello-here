# 入力値の制約

サーバー側で次の制約を検証する。

| 対象 | 制約 |
| --- | --- |
| ユーザー名 | 必須、50文字以内 |
| メールアドレス | 必須、メールアドレス形式、255文字以内 |
| パスワード | 必須、8文字以上128文字以内 |
| 表示名 | 必須、50文字以内 |
| 自己紹介 | 160文字以内 |
| 投稿本文 | 140文字以内。画像がない場合は本文必須 |
| 緯度 | 必須、-90以上90以下 |
| 経度 | 必須、-180以上180以下 |
| 投稿画像 | PNGまたはJPEG、最大4枚、1枚5MB以下、縦横4096px以下 |
| アバター画像 | PNG・JPEG・GIF、5MB以下、縦横200px以上4096px以下 |

画像は、画像全体を展開する前にヘッダーから縦横サイズと実体形式を検証し、申告されたContent-Typeとの一致も確認する。
